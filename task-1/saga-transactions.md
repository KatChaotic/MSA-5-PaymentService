# Таблица Saga-транзакций

## Описание процесса

Ключевой бизнес-процесс OrchestrPay — обработка платежа на маркетплейсах. 

Основной сценарий, который вам предстоит спроектировать и разработать:
1. Пользователь оформляет заказ и инициирует платёж.
1. Система списывает деньги с его счёта.
1. Выполняется проверка в антифрод-системе и внешних сервисах (детализация этих проверок за скоупом задания).
1. Если проверка пройдена успешно, деньги переводятся контрагенту.
1. Если операция признаётся подозрительной — она блокируется, клиенту мгновенно возвращаются деньги, а в систему безопасности уходит уведомление для анализа.

Необходимо учитывать, что сервис антифрод-проверок может возвращать три типа ответа:  
1. **Разрешение** — транзакция может быть проведена.
1. **Запрет** — транзакция отклоняется.
1. **Ручная проверка** — транзакция направляется на рассмотрение оператору, который должен принять решение в течение 20 минут. По результатам ручной проверки сервис возвращает одно из окончательных решений: разрешение или запрет.

Соответственно на время ручной проверки транзакция должна находиться в состоянии ожидания. А если сервисы проверок не возвращают ответ в установленное время, то предусмотрен cut-off-time. По его истечении транзакция по умолчанию считается разрешённой и проводится.  

## Транзакции

| Транзакция | Описание | Тип | Компенсаций | 
| --- | --- | --- | --- |
| **CREATE_PAYMENT** | Создает информацию о проведении нового платежа, инициируется транзакция | Компенсируемая | **ABORT_PAYMENT** |
| **BANK_RESERVATION** | Резервация средств клиента на стороне банка | Компенсируемая | **ABORT_BANK_RESERVATION** |
| **FRAUD_VALIDATION** | Инициация процесса валидации платежа в антифрод система | Повторяемая | |
| **BANK_WITHDRAW** | Платеж был подтвержден, списывает деньги со счета клиента | Необратимая | **BANK_REFUND** |
| **PARTNER_TRANSFER** | Переводит средства на счет партнера | Повторяемая |
| **PAYMENT_COMPLETED** | Перевод был завершен, транзакция завершается | Повторяемая | |
| **FRAUD_MANUAL_CHECK** | Заявка отправляется на рассмотрение оператору | Повторяемая | |
| **FRAUD_NOTIFICATION** | Отправка уведомления в систему безопасности | Повторяемая | |
