# Набор тестов

| Название | Тип | Компоненты | Предусловия |
| ---- | --- | --- | --- |
| **End2End**
| Happy-path оплаты | e2e | Сервис платежей, Сервис антифрода, Платежный шлюз, Сервис уведомлений | Все сервисы доступны, сервис антифрода подтверждает платеж |
| Ручное подтверждение | e2e | Сервис платежей, Сервис антифрода, Платежный шлюз, Сервис уведомлений | Все сервисы доступны, сервис антифрода требует ручную проверку платежа |
| Отмена по таймауту в антифроде | e2e | Сервис платежей, Сервис антифрода, Платежный шлюз, Сервис уведомлений | Все сервисы доступны, сервис антифрода требует ручную проверку платежа |
| Проверка таймаута банковского АПИ | e2e | Сервис платежей, Сервис антифрода, Платежный шлюз, Сервис уведомлений | Сервис антифрода одобряет платеж, банковский сервис возвращает ошибку на разных этапах |
| **Интеграционные**
| Проверка уведомлений | интеграционный | Сервис уведомлений | Подготовить тестовый smtp сервер, тестовая очередь сообщений |
| Проверка шлюза платежей | интеграционный | Шлюз платежей | Подготовить тестовый АПИ банка, тестовая БД |
| Проверка сервиса платежей | интеграционный | Сервис платежей | Подготовить тестовый АПИ шлюза платежей, тестовая БД, тестовая очередь сообщений |
| Проверка сервиса антифрод | интеграционный | Сервис антифрод | Подготовить очередь платежей, тестовую БД |
